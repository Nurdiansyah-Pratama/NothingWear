# Watch Face Workspace (`watchface-workspace`)

Design workspace for NothingWear Watch Face Studio (scheduled for M5).

- `themes/`: Preset definitions for Nothing, Minimal, Analog, Cyberpunk, Tactical, and Custom themes.
- `assets/`: Original, non-proprietary graphic assets (466 × 466 px target canvas).
- `exports/`: Output staging for physically verified Xiaomi Watch S4 export formats only.

Reminder: A visual preview is not an installable watch face.
